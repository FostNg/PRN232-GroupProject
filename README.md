# PRN232-GroupProject

RoomRum group project. The current ASP.NET Core API is in [`PRN232-RoomRum`](PRN232-RoomRum/RoomRum.API/README.md).

Build the N Layer solution with `dotnet build PRN232-RoomRum/RoomRum.API.slnx`.
The API uses `RoomRum_db`; see its README for local configuration, database migrations and verification scripts.
